# Pigment Census: test brief

Turn an original grainy, layered landscape into broader pigment patches. Compare variance-selected quadrants with ordinary box averaging on a controlled edge and constant image.

The user delegated selection of five distinct test mechanisms. Visual choices are test-fixture defaults. No external image, audio, camera or network input is required. Delivery is an isolated native component, GLSL, reproducible teaching presets, a detailed tutorial and scoped evidence.
