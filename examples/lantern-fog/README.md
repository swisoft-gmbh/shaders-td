# Lantern Fog

[Full tutorial](article.md) · [Research](research.md) · [Review](review.md) · [Native component](native/study.tox)

Make two lit helical density ribbons suspended in a dark volume. Teach view transmission and light visibility as different quantities, and test step-size consistency with a homogeneous slab.

Open `out` after importing the component. Use the Study page or the named presets in the tutorial. Each directory contains portable shader source, the native builder, experiment controls, evidence and source credits.
