# Maintainer records

Provenance and audit records for the reference library. No skill needs them
for a task; they are here so a maintainer can see how the library was
assembled and checked.

| File | What it records |
| --- | --- |
| `archive-assessment.md` | Which parts of the collected archive went into the library, and why. |
| `coverage-audit.json` | A keep-or-skip decision for each catalogued article, repository and gist. Built from the articles, so CC BY-NC 4.0 (see [NOTICE.md](../NOTICE.md)). |
| `coverage-recheck.md` | A second pass that reconciles the archive with the installed corpus. |
| `live-audit-2026-10-20.md` | A check of the live site against the corpus on 20 October 2026. |
| `live-check-2026-11-14.md` | The same check on 14 November 2026, plus his repositories, gists and playground site. |
| `native-archive-audit.json` | The search for TouchDesigner files in the archive (none found). |
| `*-archive-catalog.json` | Inventories of the collected repositories, gists, historical source files and replay resources. |
| `brand-provenance.json` | Where the design-system snapshot came from. The plugin no longer uses its colours. |

Paths inside these records that start with `Downloads/` refer to the
maintainer's private archive, which is not part of the plugin.
